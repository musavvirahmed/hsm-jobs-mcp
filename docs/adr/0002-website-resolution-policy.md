# Website resolution policy (KvK → official website)

We resolve each recognised-sponsor KvK to at most one accepted **official website** host (else **unresolved**), via Wikidata → domain-guess → search, validated with name tokens and never Wikidata alone. Prefer jobs-likely brand hosts (including careers subdomains); many KvKs may share one host; production identity comes from a current register (wrap hsm-mcp or gated IND HTML), not the GitHub mirror. Operator **website overrides** may pin a host or force unresolved; clients cannot rewrite the shared index. KvK Open Dataset and paid Basisprofiel stay out of v1.

**Considered options:** ranked candidate lists; holding-legal site over brand; 1:1 host↔KvK; client-session overrides; Wikidata-only v1; Open Dataset / paid Basisprofiel in the cascade — rejected for coverage, honesty, or map scope.
