# Partial-index ship rule (private vs shared)

v1 may **private-release** on a **partial index** after the **golden test** passes and every jobs-tool response carries **index scope**; a **shared release** (hosted or multi-user) waits for a **full careers pass** — every current Work-register KvK has a queryable **terminal careers outcome**. Register churn that leaves any KvK without an outcome immediately reverts status to `partial`. Empty searches on `partial` must set **omissions_possible** true; on `full_careers_pass` it is always false. ATS-heavy corpora are an allowed private shape, not a named ship stage.

**Considered options:** wait for a full ~13k careers pass before any use; allow shared use on ATS-detectable sponsors only; stay `full_careers_pass` across monthly register deltas; silent empty results with counts alone — rejected because they recreate false emptiness or false completeness for kennismigrant job-switchers.
